Agentic Desktop kjører allerede i nettleseren

Agentic Desktop bruker allerede datamappen

En annen server bruker den samme datamappen, , på port . Appen starter ikke sin egen server mot den samme mappen, så trådene aldri blir skrevet fra to steder samtidig.

Appen kan avslutte nettleserversjonen for deg, på samme måte som Ctrl+C i terminalen. Kjøringer som pågår der, stopper.

Stopp serveren i terminalen der du startet den med npm start (Ctrl+C), og trykk Prøv igjen.
